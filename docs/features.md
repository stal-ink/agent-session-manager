# 功能说明

本文按界面区域描述交互行为。

## 会话列表

合并所有已安装插件提供的会话。支持按 agent 过滤，按标题或工作区搜索。状态栏右侧的排序下拉提供「平铺」与「工作区」两种方式。

加载期间刷新按钮显示「刷新中…」并禁用。重复刷新只保留一次补跑，旧一轮的结果晚到会被丢弃，不会覆盖新结果。某个 agent 读取失败时保留其余 agent 的成功结果，并在列表上方提示失败原因。插件跳过无法解析的单条会话时，提示条显示未解析数量；点击「查看详情」打开可滚动的完整错误和警告列表。

搜索框聚焦时展开工作区下拉，列出当前 agent 筛选与搜索词命中的工作区，最多 5 个，超出以省略号表示；点击某个工作区即把其路径填入搜索框并过滤，光标停在末尾，不影响手动输入搜索。点击搜索框以外区域收回焦点与下拉。

每行右侧标记状态，优先级从左到右：已删除、工作区归档/删除、已归档、活跃中。颜色分别为红、灰、黄、绿。

状态来源：

- 已删除：插件返回 `deleted`。软删除的会话保留在列表并标为已删除，硬删除的会话不再出现。
- 工作区归档或删除：插件返回 `workspace_deleted`。
- 已归档：插件返回 `archived`。没有归档状态的客户端可按插件规则把未打开的会话归入已归档。

平铺排序按状态分块：活跃中、已归档、工作区归档/删除、已删除。块内按工作区聚合，同一工作区连续。工作区与其内部会话均按更新时间倒序。

工作区排序把同一工作区的会话聚成一组，组间按组内最新更新时间倒序，组内仍按状态分块再按更新时间倒序。每组以全宽分组标题显示展开三角、工作区名、完整路径与会话数，颜色全部取主题令牌，不随 agent 变化，也不显示相对时间。点击标题展开或收起该组，收起状态在本次运行内保留。

每条会话有两个动作：转接与打开。目标 agent 列表由适配器注册表生成，只读 agent 不作为转接目标。

状态栏提供四种状态复选框，可单独显示某一状态；右侧排序下拉切换平铺/工作区。顶部「全选」按当前筛选结果勾选或取消勾选。

## 转接

转接对话框选择目标 agent、目标工作区与模式。目标 agent 只列本机检测到已安装、且插件声明可写的产品；卸载后立即从目标列表移除。结果用对话框提示：成功后可立即打开目标应用；目标应用运行中时询问是否关闭，确认后关闭、完成转接并重新打开；失败显示错误原因。

### 原生转接

写入目标存储，会话出现在目标应用列表并可续聊。

声明排他的插件要求目标应用完全关闭。若正在运行，对话框询问是否关闭后完成转接并重新打开。关闭时先请求正常退出，5 秒内未退出则强制结束进程树，未保存内容可能丢失。

声明不排他的插件由自身协调共享状态，宿主只完成备份与调用。插件声明会话锁时，活跃锁拒绝写入，过期锁不阻塞。

写入前自动备份目标数据库；正文不在数据库里的 agent 同时备份正文目录。备份与回滚细节见 [safety.md](safety.md)。

再次转接同一会话时：

- 源会话在上次转接后有更新：覆盖目标端旧副本。
- 源未更新且目标端仍活跃：提示已转接过。
- 目标端已归档或删除：重建并恢复活跃。

转接完成后目标会话恢复为活跃：清除归档与删除标记，恢复所属工作区/项目。

设置页开启「仅注入最近压缩之后的消息」后，原生转接以最近一次压缩为边界，之前的对话不再写入目标端，压缩摘要保留。默认关闭即全量写入。

### 交接文档

与批量导出的交接文档同一实现、同一目录 `exports/handoff/`、同一设置开关。不写目标存储，目标应用运行时可用。

## 打开

打开行为由插件 manifest 的 `open` 策略决定：桌面端、CLI 与 VS Code 扩展按各自声明启动；带会话 id 时优先使用插件声明的续聊参数或深链。未声明会话级深链时，打开只定位到工作区，会话需在客户端内选择。各插件的具体入口见插件包 README。

选中的形态被卸载时，本次回退到其余已安装形态。选择保留，重新安装后恢复。

## 导出

普通文档全量保留消息、思考、工具调用与截断输出。

交接文档按固定规则从原文裁剪重排：目标、约束、已完成、未完成、关键路径、最近语境、前情。同一会话每次输出一致。逐条处理规则见 [handoff-export.md](handoff-export.md)。

两类导出各自遵循设置页中对应分类的「导出工具调用结果」开关。

## 批量操作

每条会话左侧可勾选。顶部「选择」打开操作窗口，按 agent 汇总已选数量，可单独取消某 agent 或全部取消。分割线下提供「导出」「删除」「销毁」。

导出先弹出方式选择，每次选择普通文档或交接文档，不记忆默认方式。

删除前再次确认。删除走各 agent 原生语义，失败自动回滚。

销毁为物理删除。确认框需勾选「我已知晓不可恢复」后才能点击，执行前列出选中分布，并注明删除本身即物理删除的插件。结果逐条报告。

## Agent 管理

顶部为「已安装 N / 未安装 M」两个页签，轨道内的滑块随选中项移动，点击切换。两区各自是滚动列表。

已安装区按产品分组。一个产品装有两个及以上形态时显示产品分组标题：全宽行，左侧展开三角，中间产品名，右侧安装数，颜色全部取主题令牌。点击标题展开或收起。单形态产品不显示标题。带分组标题的产品组置顶。组与单形态行各自按可更新、最新、未知排序。

行按「Agent / 当前版本 / 最新版本 / 状态 / 操作」展示。Agent 列显示插件声明的形态名称，不显示安装路径。

未安装区平铺本工具支持但本机未安装的形态，列为「工具 / 最新版本 / 操作」，保留安装入口。一个形态都没装的产品不进入侧栏与会话列表。

页头「检查」按钮单线程依次检查已安装形态与未安装条目，每完成一个渠道就追加一条日志并刷新对应行。检查中显示旋转图标与「检查中…」。自动检查由设置「自动检查更新」控制，默认开启：启动后延迟 5 秒检查一次，之后每 20 分钟检查一次；关闭后只保留手动触发。检查在后台线程进行，不阻塞界面。存在可更新时侧栏「Agent 管理」右侧显示 6px 红点。

操作列用「启动」与「下载」两个图标。启动直接打开对应形态，不打开任何会话：桌面端与 VS Code 扩展启动应用本身，CLI 在用户主目录新开终端。下载图标只打开对应下载页，不自动下载安装；已安装行在可更新且有下载页时可用，未安装条目在有下载页时可用，不满足条件时图标为灰色且不可点击。

检查失败不伪造版本，保留上次成功的最新版本。失败信息只写入信息浮层的检查日志。检查结果按渠道缓存本机，跨启动保留。检查日志只在内存实时更新。

渠道默认值来自已安装插件 manifest；数据目录 `update-sources.json` 可按渠道覆盖 Agent 产品版本检查页 `version_url`、Agent 产品下载页 `download_url` 与通用解析规则，编辑后下次检查生效。

页头 (i) 图标悬浮展开 360×320 信息浮层。「下载」页签为下载面板占位。「检查」页签显示最近 20 条检查日志，最新在上，可滚动。

## 插件

侧栏「插件」页分为「已安装 / 未安装」两个页签，页头提供「检查」「导入」按钮、上次检查时间与信息图标。没有任何已安装插件时默认打开「未安装」页签。插件索引检查到可更新插件时，侧栏「插件」项显示红点，与 Agent 管理页一致。选择文件后才显示「导入中…」；取消文件选择不改变界面状态。

「已安装」列表每行显示图标、名称、id、版本、形态与能力摘要、更新状态、下载图标、启用开关与卸载按钮；没有插件时显示空状态。

「未安装」列表来自插件索引的实时检查结果：显示图标、名称、版本与安装按钮，安装时显示进度并复用下载校验与严格导入流程。索引成功获取后写入本地缓存；网络失败时优先展示缓存，没有任何缓存时在列表中间显示「插件库信息获取失败」。

更新状态与启用开关无关：可更新显示绿色小字「可更新」，没有更新显示「最新」；更新成功显示「已更新」，从索引新装的插件显示「已安装」；检查中、下载中、导入中显示对应进度文字；索引检查或更新失败显示红色。右侧下载图标只在可更新时可用，其余状态置灰且不可点击；点击后只更新该插件，直接走严格导入，保留原启用状态，成功后才刷新能力，不重启应用。信息图标展开与 Agent 管理页相同的浮层，含「下载」「检查」两个页签：下载页显示速度、进度条，下载完成后显示「下载完毕，正在安装…」，最终区分「更新完毕」与「安装完毕」；检查页保留最近 20 条日志。

关闭启用开关会立即把该插件从侧栏、转接目标、产品目录与扫描目标中移除，插件包保留。卸载需二次确认，只删除插件包与注册信息，不删除该 agent 的会话数据。

导入、启用、停用、在线更新或卸载成功后，插件页、侧栏筛选、会话列表、Agent 管理、安装检测与版本源立即刷新，不需要重启；失败保留原状态并提示错误。在线更新使用固定 `plugins` 预发布标签下的签名索引与插件 zip，校验 SHA-256 与签名后才导入。只接受压缩包，格式与校验规则见 [plugin-architecture.md](plugin-architecture.md)。

## 设置

侧栏左下角齿轮打开整页设置，覆盖主界面与左侧栏。「返回应用」或 Esc 回到主界面。返回后页面、筛选与选中状态保留。

左栏自上而下为「返回应用」、搜索框与两组带图标菜单。搜索框带放大镜图标，过滤菜单与设置项，无结果显示「没有匹配的设置」。菜单分为「个人」与「关于」。「个人」包含外观、导出与交接、转接、打开、更新。「关于」包含数据与关于。

「打开」栏常驻。每个已安装且可打开形态不少于 2 个的产品一行：产品名、已安装形态摘要、默认打开 select。实心三角指示，展开时朝上。选项只含已安装且可打开的形态。选择即时保存并覆盖目录建议值。没有符合条件的产品时该栏只显示标题与说明。

「更新」栏提供「自动检查更新」开关，默认开启。开启时启动后延迟 5 秒检查一次，之后每 20 分钟依次检查 App 自更新、插件索引与 Agent 产品渠道；关闭后只在点击「检查」或「检查软件更新」时请求。

内容区为大标题、说明与卡片分组。组标签在卡片外，卡片内是设置行。

### 外观

以三列卡片列出跟随系统、深色、浅色、米黄、薄荷与自定义壁纸。卡片带迷你窗口预览，切换即时生效。跟随系统卡片固定展示 Windows 当前深浅主题的配色。

选中自定义壁纸后下方出现壁纸行，可选择本地图片。导入时按 EXIF 方向校正、等比缩放后居中裁为 16:10，最长边不超过 2560×1600。图片存到数据目录，不引用外部路径。

### 导出与交接

分为「普通文档导出设置」与「交接文档导出设置」两组。各只有「导出工具调用结果」一个开关。

### 转接

提供「仅注入最近压缩之后的消息」开关，默认关闭。

### 数据与关于

提供打开数据目录、备份目录、导出目录、插件目录与应用版本。

「关于」卡片在版本行下方提供「软件更新」：显示上次检查时间与状态，按钮依次表示检查、更新到 vX、下载中、立即更新或重试。下载与验签完成后弹出确认框，可选择「立即更新」或「稍后」；稍后保留已下载文件，下次点击「立即更新」直接安装。替换由退出后的 helper 完成，失败自动恢复旧版本。

侧栏左下角版本号右侧的更新入口只在明确发现新版本后出现：可更新或已下载显示绿色下载图标，下载中显示转圈；悬停显示一句话说明。检查中、检查失败、没有新版本或尚未检查时不显示按钮。点击与设置页按钮共用同一状态机。

所有改动即时保存到 `config.json`。侧栏左下角齿轮左侧的文件夹按钮直接打开应用数据目录。

## 托盘与窗口

窗口使用无边框自绘标题栏。标题栏支持拖动与双击最大化，右侧提供最小化、最大化/还原与关闭。边缘可拖动缩放。

最小化保留在任务栏。关闭窗口隐藏到托盘。托盘左键恢复窗口并置顶，右键菜单显示主界面/退出。

单实例运行。重复启动 exe 不再开第二个进程，只把已运行的窗口唤到前台后退出。

多显示器：100% 与 150% 混合缩放下跨屏拖动窗口保持逻辑尺寸，不级联放大。DPI 修正由窗口过程钩子处理。

## 主题

跟随系统、深色、浅色、米黄、薄荷与自定义壁纸。调色板定义在 `assets/themes/*.json`，启动与切换时由 Rust 应用。跟随系统读取 Windows 应用主题 `AppsUseLightTheme`。壁纸主题以本地图片铺底、面板半透明，未选图片时使用纯色底。

## 其他

垃圾会话清除：扫描所有 agent 中 0 条消息且未删除的会话，按 agent 汇总，确认后复用批量删除的备份与回滚流程。
