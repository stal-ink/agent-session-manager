# 已知限制

## 通用

- 上游应用更新可能导致存储 schema 漂移，届时需按新 schema 调整对应插件。
- 图片与附件通常降级为引用文本，不搬运二进制；具体行为由插件写入器决定。
- 超长会话注入耗时在秒级。
- DPI 修正仅覆盖 64 位 Windows。窗口吸附跨屏未单独验证。winit 0.30 上游修复发布后可移除本地补丁。

## 打开与安装

- 打开行为由插件 manifest 的 `open` 策略决定。未声明会话级深链时，只能启动应用或定位到工作区，会话需在客户端内选择。
- 安装检测只覆盖已声明的检测器类型。免安装、未注册或无法识别的副本会显示未安装。
- 版本检查依赖插件声明的渠道与解析器。官网改版可能使某个渠道失效，失败信息写入检查日志。

## 插件

- 插件只实现短命进程，daemon 字段保留但拒绝加载。
- 插件页提供导入、列表、启停、卸载，以及来自插件索引的在线安装与更新；没有热重载。签名验的是索引清单，插件 zip 本身不单独签名。
- RAR 不列入支持格式。
- 7z 的符号链接识别依赖 Windows 重解析点属性，Unix 侧创建的 7z 符号链接不保证可识别。
- 插件进程隔离用于防止崩溃拖垮宿主，不是安全沙箱。
- 各插件的存储格式、写入范围与真实续聊验证状态见对应插件包的 `README.md`。
